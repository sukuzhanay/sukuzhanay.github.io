## Visibility maintenance — 2026-11-25

The portfolio links the AWS architecture guide and official individual Credly credential. The QR Covid structured-data credit uses contributor to reflect academic/technical direction within a collaborative project.

After a successful GitHub Pages `pages-build-deployment` workflow, `notify-indexnow.yml` checks the deployment head for changes to index.html/styles.css, verifies the public ownership file and sends the home URL to IndexNow. No secrets or write permissions are used. A multi-commit push whose final commit changes only other files can be skipped; manually notify if needed. HTTP 200/202 does not prove indexing. The workflow is event-driven, not a recurring campaign.


The architecture guide is published at https://sukuzhanay.github.io/topics/aws-data-architecture/ with its own canonical URL and RSS feed. The notification workflow compares the complete push, waits for the matching Pages deployment to succeed, verifies live URLs and ownership, then submits changed HTML pages to IndexNow. It uses read-only repository permissions, no third-party Actions and no stored external credentials. New shared-style consumers should be included in its stylesheet mapping. Removed pages are deliberately excluded and require separate handling. HTTP acceptance is not evidence of indexing.
